📋 Cách khởi động (Máy Chủ — máy bạn)
1
Mở thư mục chứa file ketoan-phu-anh.html
2
Click vào thanh địa chỉ Windows Explorer → gõ cmd → Enter
3
Nhấn nút "Tải server.py" bên dưới → đặt vào cùng thư mục với file HTML
4
Trong cửa sổ CMD, gõ lệnh và Enter:
python server.py
5
Server khởi động → ghi lại IP hiện ra (VD: 192.168.1.x:8765)
🖥 Máy Chủ: Sau khi chạy python server.py, nhấn Kết Nối để app kết nối tới server local.
Máy client nhập IP máy chủ, chọn "Máy Client" → Kết Nối. Dữ liệu đồng bộ tự động mỗi 30 giây.
💻 Máy Client: Nhập IP của máy đang chạy python server.py rồi nhấn Kết Nối.
Yêu cầu: cùng mạng LAN, máy chủ đã bật server.py
